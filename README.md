# Mrcpuddington KiCad repository

Custom KiCad Plugin and Content Manager catalogue for Kobee Studio and future
Mrcpuddington KiCad tools.

## Add to KiCad

Stable catalogue:

```text
https://raw.githubusercontent.com/mrcpuddington/mrcpuddington-kicad-repository/main/repository.json
```

Testing catalogue:

```text
https://raw.githubusercontent.com/mrcpuddington/mrcpuddington-kicad-repository/testing/repository.json
```

The testing catalogue is intentionally separate from the stable catalogue.
Only add it when you want to test pre-release packages.
